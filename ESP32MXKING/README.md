Firmware + Dashboard untuk komunikasi K-Line dengan Yamaha MX King V2.

## Struktur
- `firmware/` - Kode ESP32 (C++)
- `dashboard/` - Web UI (HTML/CSS/JS)
- `docs/` - Dokumentasi
